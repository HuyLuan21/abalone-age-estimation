# Data Dictionary

| Thuộc tính     | Kiểu dữ liệu | Đơn vị | Mô tả                                          |
| -------------- | ------------ | ------ | ---------------------------------------------- |
| Sex            | Nominal      | -      | M (Male), F (Female), I (Infant)               |
| Length         | Continuous   | mm     | Chiều dài lớn nhất của vỏ                      |
| Diameter       | Continuous   | mm     | Đường kính vuông góc với chiều dài             |
| Height         | Continuous   | mm     | Chiều cao (bao gồm thịt trong vỏ)              |
| Whole_weight   | Continuous   | g      | Khối lượng toàn bộ                             |
| Shucked_weight | Continuous   | g      | Khối lượng thịt                                |
| Viscera_weight | Continuous   | g      | Khối lượng nội tạng                            |
| Shell_weight   | Continuous   | g      | Khối lượng vỏ sau khi sấy                      |
| Rings          | Integer      | -      | Số vòng trên vỏ; tuổi xấp xỉ = Rings + 1.5 năm |
